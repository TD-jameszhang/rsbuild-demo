使用Git凭证存储 ​

Git提供了一种凭证存储机制，可以在本地计算机上存储用户名和密码。 一旦存储了凭证，Git会自动使用这些凭证进行身份验证，而不需要每次都手动输入密码。可以使用以下命令配置凭证存储：

bash
git config –global credential.helper store
