React 编码风格 ​

取一个好的名字 ​

基本原则:

  • 使用大小写英文字母和下划线 中划线组成
  • 不能使用关键字和保留字
  • 能见名知意
类型命名规则举例
项目名英文小写/分隔符用中划线con-core
目录名英文小写/分隔符用中划线kcs, shared-library
图片名英文小写, 分隔符用中划线,带精度login-bg@2x.png
组件名大驼峰NavBar
常量名英文大写,分割符用下划线PRODUCT_INFO
变量名小驼峰命名法, 布尔类型用is/has开头userInfo isLoading
方法名小驼峰命名法getUserInfo
组件属性名小驼峰命名法activeKey
Hooks小驼峰命名法, 以use开头useResize
样式类名英文小写,分割符用中划线modal-btn

合理组织代码 ​

在组件内, 可根据如下顺序来组织您的代码:

  1. 变量定义(如: 解构props) && useState && other hooks
  2. functions (handleX)
  3. useEffects
  4. render function

示例代码 ​

ts
import React, { useState, useEffect } from 'react'
import logger from '@ca/logger'

import useTabManager from './useTabManager'

const DemoTab = (props) => {
  const { isActive, tabs } = props
  const [ activeTabId, setActiveTabId ] = useState(tabs[0].id)
  const tabManage = useTabManager(tabs)

  useEffect(() => {
    if(isActive){
      logger.log('enter demo tab!')
    }
  }, [isActive])

  const clickHandler = (id) => () => {
    setActiveTabId(id)
  }

  return (
    <div>
      {tabs.map((tab, index) => {
        <span key={index} data-tab-id={tab.id} onClick={clickHandler}>{tab.name}</span>
      })}
    </div>
  )
}

hooks使用 ​

重要!!!

  1. 只在顶层使用Hooks(不要在循环、条件或嵌套函数中使用hook)
  2. 只在React函数中调用Hook(不要在普通的JavaScript函数中调用hook)

建议 ​

  1. hooks命名,必须以 use为前缀(例如: useResize)
  2. 所有的hooks都提取到一个目录下(例如: context-hooks), 每个hooks都是一个文件. 例如: context-hooks/useResize.js

函数 ​

  1. 函数职责尽量单一, 行数最好不要超过50行, 函数复杂度建议不要超过5 (可通过eslint配置规则控制)
  2. 超过1个地方的重复逻辑, 则封装成函数, 超过2个地方使用的函数,则建议提取成工具函数.
  3. 函数与函数之间用一个空行隔开.

函数式组件定义 ​

React 提供了一个组件类型 React.FunctionComponent, 可简写为 React.FC

  • 可以接收一个泛型p, 默认是 {}
  • React.FC为children提供了隐式的类型(ReactElement|null), 编码时亦可显式的写出来
ts
import React from 'react'

type Props = {
  isOpen?: boolean
  onClick?: () => void
}

const NavBar: React.FC<Props> = ({
  onClick?: () => void,
  isPanelOpen = false
  children?: React.ReactNode
}) => { 
  // some codes
}
ts
const NavBar: React.FC<{
  isOpen?: boolean,
  children?: React.ReactNode
  onClick?: () => void
}> = ({
  onClick?: () => void,
  isPanelOpen = false
}) => { 
  // some codes
}
